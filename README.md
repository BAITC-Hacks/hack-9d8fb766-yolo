# FAQ-бот: терминал + Telegram + OpenAI

Бот отвечает на пять тем репетиции: время, команда, трек, сдача и призы. В `faq.txt` сохранены пять пар вопрос–ответ. Нужен **Python 3.10+**; сторонних библиотек нет.

## Запуск

Терминальный чат работает без ключей и интернета:

```bash
python bot.py
```

Для Telegram скопируйте `.env.example` в `.env` рядом с `bot.py` и заполните `TELEGRAM_BOT_TOKEN`. Для ИИ дополнительно заполните `OPENAI_API_KEY` ключом OpenAI API. В подготовленной локальной папке Telegram-токен уже записан; в архиве для сдачи секретов нет. Модель задаётся в `OPENAI_MODEL` (по умолчанию `gpt-4.1-mini`). Затем:

```bash
python bot.py --check
python bot.py --telegram
```

В Windows можно открыть `start-telegram.cmd` двойным щелчком. Бот работает, пока запущен процесс и компьютер подключён к интернету. Остановка — `Ctrl+C`. После изменения `.env` перезапустите процесс. Системные переменные окружения имеют приоритет над `.env`.

## Что получилось

- `/faq` показывает все пять ответов; `/help` — справку.
- `/classic` — поиск по ключевым словам. Нет совпадения или равенство тем → «Не знаю».
- `/auto` (по умолчанию) — сначала ключевые слова, при отсутствии ответа — OpenAI, если задан ключ.
- `/ai` — каждый вопрос разбирает OpenAI: понимает перефразирования и выбирает подходящие ответы из FAQ. Если ответа нет — «Не знаю». Модель возвращает номера пунктов; текст берётся из файла, поэтому новые факты не генерируются. RAG и база векторов не используются.
- При ошибке OpenAI бот возвращается к ключевым словам и сообщает об этом. Без ключа доступен обычный FAQ. Запросы OpenAI используют квоту вашего API-аккаунта; провайдеру передаются вопрос и FAQ, без Telegram-токена и данных профиля.

Команды режимов работают и в терминале; выход — `выход`. Режим Telegram общий для чата и сбрасывается при перезапуске. В группе используйте упоминание бота, ответ на его сообщение или `/faq@имя_бота`. Обрабатываются текстовые сообщения, включая ожидающую очередь. Запускайте только один экземпляр: при активном webhook или конфликте Telegram покажет ошибку, настройки webhook автоматически не меняются.

Проверка: `python -m unittest discover -s tests -v`. Тесты проверяют FAQ, режимы, ответы и ошибки API с подменой сети. `--check` проверяет настоящий Telegram-токен без чтения/отправки сообщений; наличие ключа OpenAI не означает успешный запрос к ИИ. Живой ответ OpenAI нужно проверить после добавления ключа командой `/ai` и вопросом «За это что-нибудь дадут?».

Для сдачи загрузите исходники, `faq.txt`, `.env.example` и README в репозиторий команды. **`.env` не публикуйте** — он исключён через `.gitignore`.

Документация: [Telegram Bot API](https://core.telegram.org/bots/api), [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs).
